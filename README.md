# VeriFed-Edge: Verifiable Unlearning for Healthcare Federated Learning

## Overview
This repository contains the implementation of **VeriFed-Edge**, a framework designed for verifiable machine unlearning within healthcare federated learning environments.

## Features
- **Verifiable Unlearning:** Enables privacy-compliant removal of client data contributions.
- **Healthcare Edge Integration:** Designed for distributed and privacy-sensitive medical data applications.

## Project Structure
- `src/`: Core source code and implementation modules.
- `codes_and_docs/`: Supporting documentation, scripts, and auxiliary code.
